# GereBank

GereBank é um sistema de gerenciamento bancário desenvolvido para simular operações financeiras básicas, com foco em backend, segurança e manipulação de dados.

## Funcionalidades
- Cadastro de usuários
- Autenticação de usuários com senha criptografada
- Gerenciamento de contas bancárias
- Realização de transações (depósitos e saques)
- Registro e visualização de transações financeiras
- Geração de relatórios financeiros

## Objetivo do Projeto
Este projeto foi desenvolvido com o objetivo de aplicar conceitos de desenvolvimento backend em um sistema financeiro, envolvendo autenticação, regras de negócio e persistência de dados em banco relacional.

## Tecnologias Utilizadas
- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- XAMPP

## Conceitos Aplicados
- CRUD (Create, Read, Update, Delete)
- Autenticação e controle de acesso
- Criptografia de senhas
- Manipulação de dados financeiros
- Integração com banco de dados relacional
- Organização do fluxo backend
